# 時間の墓場

![時間の墓場](tmp/time-graveyard.png)

---

2025年が終わった。

あなたはそのことに気づいていなかった。気づいたときには、365日すべてが海の底に沈んでいた。

---

深海には墓標が立っている。

ピンク色に光る十字架。それは、あなたが過ごしたはずの日々だ。1月1日。3月14日。8月の暑い日。12月の寒い夜。すべてがここにある。すべてが、ここに沈んでいる。

あなたは潜水艦に乗っている。なぜここにいるのかは覚えていない。ただ、十字架を見つけなければならないという衝動だけがある。

---

あなたは「記憶」と呼ばれている。

もう一隻の潜水艦がいる。赤い光を放つそれは「忘却」と呼ばれている。

忘却は、あなたより先に十字架を見つける。見つけた十字架は灰色に変わり、二度と光を取り戻さない。

いや、違う。

あなたが近づけば、灰色の十字架はまた光りはじめる。記憶は、忘却に勝てる。

しかし忘却もまた、あなたが見つけた十字架を奪いにくる。

---

深海には観測者がいる。

7つの目。7つの曜日。彼らは何も言わない。ただ見ている。あなたが十字架を見つけるのを。忘却が十字架を奪うのを。

「あなたは時間を探しているのですか」

「それとも時間に探されているのですか」

---

365本の十字架。

すべてを見つけたとき、あなたは何を思うのだろう。

すべてを忘れたとき、あなたは何を思うのだろう。
